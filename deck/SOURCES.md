## Dashboard screenshot (slide 2)

`public/img/dashboard-alert.png` (used on slide 2) and `public/img/dashboard-queue.png` (kept, not shown) are unedited screenshots of the real dashboard
(`frontend/`), served by the API on port 8765 after running the full pipeline on seed 42 from this branch, captured
by `scripts/shoot-dashboard.mjs` with Microsoft Edge on 2026-10-16. The values visible in them (for example
player P01444, score 97 Critical, $83,400.00 deposited in 30 days) are synthetic pipeline output, not committed data.
The dashboard's top bar is cropped off; nothing inside the images is edited. No LLM was configured
(`LLM_PROVIDER=none`), so the case summary shown is the built-in template.

The rerun reproduced the committed validation exactly: `validate.py` rewrote `docs/VALIDATION.md` with
line-ending changes only, and that rewrite was discarded with `git checkout`.
